# SoC

## Reading the ADT

```sh
ipsw extract --pattern 'DeviceTree.*' -o work <ipsw>
ipsw img4 im4p extract -o build/adt-d331p.bin \
    work/*/Firmware/all_flash/DeviceTree.d331pap.im4p
cd build/m1n1/proxyclient
../../venv/bin/python -c '
from m1n1.adt import load_adt
adt = load_adt(open("../../adt-d331p.bin", "rb").read())
for c in adt["/arm-io/usb-complex"]:
    print(c._path, [hex(c.get_reg(i)[0]) for i in range(len(c.reg))])'
```

Raw `reg` is an offset from the parent. `get_reg()` gives the real address.

## CPUs

CPU `reg` is `MPIDR_EL1 & 0xffffff`: 0x0 to 0x3 (E), 0x10100 and 0x10101 (P).
The ADT drops Aff2, and with its values m1n1 drops every CPU node.

## AIC

- `ps_aic` needs `apple,always-on`. Otherwise genpd turns it off and no
  interrupt arrives.
- `AIC_WHOAMI` is 4 on the boot CPU. `linux-0003` maps it.
- `TARGET_CPU` takes `BIT(AIC_WHOAMI)`.
- 1024 interrupts. Reading 0x4200 raises an abort.

## SMP

All six cores work. It needs:

- the CPU start block at pmgr + 0xd4000 (`m1n1-0008`)
- the real MPIDRs in the DT
- CPU and CPM power domains always-on
- A12 chicken bits (`m1n1-0009`)
- `apple,t8015-aic` first, for fast IPIs

CPU hotplug does not work with spin-table.

## Die temperature

`linux-0006`, `drivers/hwmon/apple-soc-temp.c`.

| sensors | base | registers |
|---|---|---|
| 0 to 4, SoC | 0x23b288000 | 32 bit, 0x4000 apart |
| 5 to 7, P cluster | 0x211e30000 | 64 bit at 0x0, 0x40, 0x200 |
| 8, E cluster | 0x210e30000 | 64 bit at 0x0 |

The low 16 bits are the temperature in 1/64 degrees. Sensor 2 reads zero and is
skipped.
